# Safety Analyst Type Test: Aricell Case

Interactive Human Factors game based on the 2024 Aricell lithium battery factory fire accident.

## Project Concept

This GitHub Pages project works like an MBTI-style test, but instead of personality types, it identifies the user's dominant accident-analysis model.

The test compares five models:

- 4M Analysis
- Swiss Cheese Model
- Domino Model
- HFACS
- SHELL Model

## How to Use

1. Open `index.html`.
2. Answer 12 scenario-based questions.
3. Check your final Safety Analyst Type.
4. Review the percentage score for each model.

## Add Images

Put your images into:

```text
assets/images/
```

Recommended filenames:

```text
hero.jpg
accident-site.jpg
battery.jpg
factory.jpg
memorial.jpg
```

The page will automatically display them if the filenames match.

## GitHub Pages Deployment

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to:

```text
Settings → Pages → Build and deployment → Deploy from a branch
```

4. Select:

```text
Branch: main
Folder: /root
```

5. Save.

Your website will be available at:

```text
https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/
```

## Presentation Use

This project can be used as an interactive add-on for a Human Factors / Industrial Safety presentation.

Recommended section:

- After explaining 4M, Swiss Cheese, Domino, HFACS, and SHELL
- Before the conclusion slide
- As a class participation activity
